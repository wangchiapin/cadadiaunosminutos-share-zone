# 遊戲 Instagram Reel 腳本

給 @cadadiaunosminutos_ben_chino 的遊戲介紹 Reel：每款遊戲一份檔案，內容有 Reel 分鏡表、賣點、學生版貼文、老師版貼文（另外發）、拍之前要確認的事。

遊戲的詳細說明以老師分享區的卡片（`index.html` 的 `guide`）和各遊戲 repo 的程式為準；遊戲改版後，這裡的腳本也要重新核對。

## 已決定的格式

- 畫面字幕和貼文都是 **中文＋西班牙文** 雙語；字幕中文大、西文小，一次一行，至少停 2 秒。
- Reel 30 秒內：0–3 秒鉤子、3–25 秒精彩片段、最後 4–5 秒結尾畫面。
- 結尾畫面固定：免費玩 Juega gratis｜連結在簡介 Link en la bio（連結放簡介，不用留言關鍵字）。
- 學生版貼文和老師版貼文分開發；老師版用圖片或輪播就好，不一定要做成 Reel。
- 不要從頭玩到尾，只留「連續答對」和「差點失敗」的片段，設定、載入、等待全部剪掉。
- 手機直式錄螢幕、開聲音；錄完交給 Claude 剪（切掉網址列、加雙語字幕、加結尾畫面、音量統一）。

## 發文建議

- 先發學生版 Reel，隔 2～3 天再發老師版貼文，兩邊的人都不會被洗版。
- 不要同一天發好幾款，一週一款；簡介連結記得換成對應的那款。
- 老師版貼文用圖片或輪播就好。

## 通用注意事項

- **有沒有聲音要以遊戲實際為準。** 墨龍飛天不念字；比比看沒有語音；其他多數遊戲會念中文（程式碼和錄影的聲音波形都能對上）。字幕不要寫沒驗證過的聲音。
- 排行榜：墨龍飛天和打地鼠現在都有排行榜（舊文件寫「還沒連上網路」已過時）；比比看、數字聽力沒有排行榜，貼文不要提。
- 老師版貼文提到「訂閱」功能時，價格與開放狀況你還沒定，先不寫價格，也不寫要不要登入。
- 五款遊戲的 GitHub Pages 網址都要開好，簡介連結才有東西可以點。
- 錄影時若是舊版畫面（例如墨龍的錄影是 v1-7），發之前確認遊戲已更新到現行版本。
