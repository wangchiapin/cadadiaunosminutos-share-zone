# 打地鼠學中文 · Atrapa al Topo

- 網址：https://wangchiapin.github.io/atrapa-al-topo/
- 程度：入門～初級（句子詞序）
- 一句話賣點：打地鼠玩法，照句子的順序打出詞，練中文最難的一關——詞序。

## 成品狀態

- 已剪好：`out_mole_reel_v1.mp4`（26 秒，1080×1920）。
- 用到的片段：句子出現並念出來 → 打對字變綠 → 每個字念出來 → 拼完一句放彩帶 → 打錯一次 → 下一句。
- 這次錄影沒有拍到：連錯 3 次後「目標字發光放大」、沒有字卡的驚喜地鼠。想放的話要補錄（故意連錯 3 次）。
- 聲音：句子出現時念整句，每次打中念那個詞（程式碼和錄影波形都對得上）。

## 賣點

- 練的是中文最難的一關：句子的詞序。
- 一邊打一邊聽句子、看拼音或注音（句子上方每個詞都有）。
- 打錯不會被罵：字卡抖一下，連錯 3 次會發光提示，壓力小。
- 乾淨的無印風，地鼠可愛，手機直式玩得很順。
- 句庫 A1、A2 各 100 句，簡單／普通／困難三種難度；2 分鐘內看你能完成幾句。
